# Astra TV
<!-- impeccable:product-schema 1 -->
## Platform
android
## Stack
Kotlin, Jetpack Compose for TV, Media3, Room, DataStore. Single app module, as explicitly authorized in the brief.
## Users
Google TV and Android TV viewers using D-pad remotes and their own authorized playlists.
## Product Purpose
Import, browse and reliably play user-provided IPTV and on-demand media without an account or bundled channels.
## Operating Context
1920×1080 television, ten-foot viewing, resource-constrained hardware; Fedora build host; sideloading through ADB or Downloader.
## Capabilities and Constraints
Playback reliability, remote navigation, performance, completeness, then polish. No unauthorized content, fabricated metadata, secret logging, or invented distribution codes. Every visible action must function.
## Brand Commitments
Astra TV. Minimal charcoal surfaces, restrained cyan, readable typography, quiet borders, rounded corners. The detailed user brief is visual authority; no mockup images were supplied.
## Evidence on Hand
Empty repository. No signing identity, GitHub release destination, provider credentials, physical TV, or supplied visual mockups.
## Product Principles
Preserve library identity on refresh. Reuse one player. Parse and persist off the UI thread. Show recoverable states. Never misrepresent unavailable provider features.
## Accessibility & Inclusion
D-pad and Back throughout, visible focus, safe display margins, keyboard entry using the system TV input method.
