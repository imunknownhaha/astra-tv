# Android handheld library

Mode: Operate. Preserve Astra's charcoal/cyan identity and existing library/player
features while using native Material touch controls. Compact widths use four
bottom destinations and a drawer for the remaining destinations; expanded widths
use a rail and the same drawer. Categories become horizontal chips. Preserve
system Back, status/navigation/IME insets, 48dp targets, both orientations and
profile restrictions. Do not change the TV shell or its remote focus behavior.
