# Fedora desktop library

Mode: Operate. Native GTK 3, system font and icons, charcoal/cyan Astra colors.
A persistent sidebar carries library and management destinations, while indexed
list browsing gives names and categories space. All parsing/network work runs
outside the GTK thread. mpv owns a dedicated reusable playback window and its
native playback interactions. Show honest loading, empty and error states; never
include provider credentials or stream addresses in logs or process arguments.
